## Lint and fix

25 rules check routing descriptions, multi-agent depth, the single write agent, MCP
allowlists, auto-approve, human-in-the-loop confirmation, hard-coded secrets, insecure URLs,
waiting UX, skill drift, missing topics and formatting.

- Findings appear in the **Problems** panel with source *Agent Forge*.
- Press <kbd>Ctrl</kbd>+<kbd>.</kbd> on a finding for a **quick fix** or to disable the rule.
- **Apply All Safe Quick Fixes** fixes colon-space descriptions, skill drift, missing
  `SKILL.md` files and auto-approved writes in one step.
